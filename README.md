# stone-ocean-task-manager

*"Freedom flows like the ocean — so do your tasks."*

A JoJo-inspired Task Manager built with the **MERN stack** (MongoDB, Express, React, Node.js).  
Organize your tasks with style, precision, and a touch of anime flair.

---

## Features
- **User Authentication** (Register/Login with JWT)
- **Task CRUD** (Create, Read, Update, Delete)
- **Kanban Board** (Drag-and-drop tasks between To Do, In Progress, Done)
- **JoJo Theme** (Stone Ocean-inspired design and naming)
- **Dark Mode Toggle**
- **Deadline Reminders** (optional extra feature)

---

## Tech Stack
- **Frontend:**  React, React Router, Axios, react-beautiful-dnd  
- **Backend:**   Node.js, Express.js  
- **Database:**  MongoDB (Atlas or local)  
- **Auth:**      JWT + bcrypt  
- **Deployment:** Netlify (frontend), Render/Heroku (backend)
